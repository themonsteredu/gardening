# 가드닝 커리어 랩

학생이 실제 학교 공간을 분석하고 조경 도면을 만든 뒤, 평면 설계와 미니 조경 모델링을 거쳐 실제 작품을 제작하는 조경전문가 직업체험 웹앱입니다.

## 현재 구현 범위 — STEP 1–15

### 간소화 개편 진행 — 1단계

- 학생 입장 후 긴 브리핑과 도면 확인 화면 없이 학교 사진 중심 시작 화면 제공
- `학교조경 → 친구작품 → 미니조경 → 실제제작` 네 단계 진행 표시
- 짧은 오늘의 의뢰, 선택형 도움말, `꾸미기` 한 가지 중심 행동
- 학교 사진이 없는 경우 교사 등록을 기다리는 간단한 빈 화면
- 태블릿·크롬북에서 학교 사진과 시작 버튼이 한 화면에 보이는 반응형 구성

- 교사/학생 역할 선택
- 교사의 수업 기본 정보 생성 및 수업 코드 확인
- 학생의 수업 코드·닉네임 입장
- 실제 공간 설계 → 작품 비교 → 미니조경 설계 → 실제 제작의 전체 학습 여정 안내
- 이후 기능을 위한 도메인 타입과 저장소 인터페이스
- 브라우저 로컬 저장 기반 프로토타입 상태 유지
- JPG·PNG·WebP·PDF 학교 이미지 업로드와 드래그앤드롭
- 최대 20MB 파일 검증, 이미지 크기 확인, 등록 전 미리보기
- IndexedDB 파일 저장 및 교사 대시보드 준비도·원본 레이어 연동
- 원본 이미지 위 기존 시설 자유 다각형 작성(클릭·터치)
- 건물·운동장·보행로·녹지·수목·출입구·주차·기타 시설 분류
- 점 되돌리기, 작성 취소, 영역 이름 수정·삭제와 레이어 표시 전환
- 비율 좌표 JSON 저장 및 교사 대시보드 도면 진행 상태 연동
- 기존 시설 도면을 잠근 상태에서 조경 가능 영역을 별도 다각형으로 지정
- 여러 가능 영역 생성, 이름 수정·삭제, 원본·시설·가능 영역 표시 전환
- 조경 가능 영역 저장 시 STEP 3–4 완료와 수업 준비도 연동
- 학생용 식재·포장·시설물·경관요소 재료함 22종
- 마우스 드래그 또는 재료 선택 후 터치로 도면 배치
- 조경 가능 영역 안쪽 전체에 들어오는 경우에만 배치·이동 허용
- 배치 재료 이동, 회전, 크기 변경, 복제, 삭제와 앞뒤 순서 편집
- 학생 세션별 조경 설계 JSON 자동 저장과 수동 저장
- 새로고침 후 배치 위치·크기·회전·레이어 순서 복원
- 같은 학생 설계 URL 재접속을 위한 프로젝트·학생 컨텍스트 복원
- 저장 중·자동 저장됨·저장된 설계 불러옴 상태 표시
- 저장된 평면 좌표·크기·회전·순서를 경량 CSS 3D 장면으로 변환
- 식재·포장·시설물·경관요소별 높이와 입체 표현
- 드래그 360° 회전, 확대·축소, 위에서·정면·입체 시점 전환
- 3D에서는 읽기 전용으로 확인하고 평면 배치 수정으로 복귀
- 휴식·녹지·이동·경관 등 핵심 키워드와 설계 이유 작성
- 학생별 구조화된 설계 의도 저장 및 학급 갤러리 중복 없는 재제출
- 학생 이름, 배치도·3D 미리보기, 핵심 키워드, 설계 이유 비교
- 점수와 순위 없이 설계 목적별로 살펴보는 키워드 필터
- 교사용 미니조경 키트 이름과 투명화분 형태·실제 크기 등록
- 원형·사각형·직사각형·넓고 낮은 화분·높은 원통형 프리셋
- 화분 가로·세로·높이 직접 수정, 예상 용량과 투명화분 미리보기
- 여러 키트 저장·불러오기·복사 및 현재 수업 키트 연결
- 실제 수업 재료 JPG·PNG·WebP 사진 등록과 IndexedDB 원본 저장
- 층 재료·표면 재료·개별 물체·식물·구조물 유형 지정

- 키트별 실제 재료 편집·사진 교체와 2단계 삭제 확인
- 교사가 등록한 화분 형태·실제 치수를 학생용 3D 비율로 변환
- 투명 옆면·바닥·윗면 테두리와 내부 재료 배치 영역 표현
- 드래그 360° 회전, 확대·축소와 정면·측면·상단·입체 시점
- 친구 작품 비교 완료 후 PART 2 미니조경 모델링 흐름 연결

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 열고, 학생 데모 코드는 `GARDEN24`를 사용합니다.

## 검증

```bash
npm run test
npm run typecheck
npm run lint

```
