# 가드닝 커리어 랩 홍보영상

- `gardening-promo.mp4` — 1920×1080, 30fps, 약 55초, 배경음악 + 하단 자막 포함
- 실제 앱 화면을 내 컴퓨터(로컬)에서 켜고 데모 수업 코드 `GARDEN24`로 직접 조작하며 녹화했습니다.
  - 학생 입장 → 3D 학교에 잔디·산책로 그리기 → 나무·꽃·벤치 놓기 → 360° 입체·학생 눈높이로 둘러보기
  - 설계 의도 쓰기와 우리 반 갤러리 → 투명화분 확인과 색모래 층 쌓기 → 식물·장식 배치와 자동 제작 순서
  - 선생님 수업 설계실(수업 코드, 학생 현황, 미니조경 키트)
- 3D 화면은 녹화 컴퓨터에서 느리게 그려져서 영상 안에서 "빠르게 감기"로 보여줍니다.
- `gardening-promo.srt` — 자막 파일 (유튜브 등에 따로 올릴 때 사용)
- `source/` — 다시 만들 때 쓰는 녹화·편집 스크립트 (앱 동작이나 배포에는 영향 없음)
  - `go.mjs`·`rec.mjs` 화면 녹화, `extract.sh` 장면 이미지 추출, `compose.html`·`render.mjs` 편집·렌더링, `music.py` 배경음악 생성(직접 만든 저작권 걱정 없는 곡)

앱 배포 주소가 저장소에 적혀 있지 않아 영상 마지막에 주소는 넣지 않았습니다.
